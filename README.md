# 🐂 Bulls and Cows Game 🐄

A classic number-guessing game implemented in Python. The computer generates a secret 4-digit number with unique digits, and the player tries to guess it using feedback clues!

## 🎮 How to Play
1. The game generates a secret 4-digit number where **all digits are unique** (e.g., `1482`, not `1148`).
2. For each guess you enter, you will receive a hint:
   - **Bulls:** Correct digit in the **correct** position.
   - **Cows:** Correct digit in the **wrong** position.
3. Keep guessing until you match all 4 digits and win!
4. Type `quit` at any time to exit the game.
